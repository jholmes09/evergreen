# Evergreen

xLights 2025.11 with a small show-folder handling change, built for Windows.

- `main` = the unmodified 2025.11 release (first commit) plus the changes on top.
- Built by GitHub Actions (`.github/workflows/windows.yml`); the installer is attached to each run as an artifact.
- Upstream: https://github.com/xLightsSequencer/xLights (GPLv3). This repository is the corresponding source for the Evergreen build.
