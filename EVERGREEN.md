# Evergreen

xSchedule 2026.05 with a small show-folder handling change, built for Windows.

- `release-xschedule-2026.05` = the unmodified 2026.05 release (first commit) plus the changes on top.
- Built by GitHub Actions (`.github/workflows/windows.yml`); the installer is attached to each run as an artifact.
- Upstream: https://github.com/xLightsSequencer/xSchedule (GPLv3). This repository is the corresponding source for the Evergreen build.
